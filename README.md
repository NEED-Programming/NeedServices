# NeedServices
Features:
Identify Modifiable Services such as Unquoted Service Paths, Weak Service Permissions, Weak Service Binary Permissions, potential DLL hijacks, 

Features:
Can be run in Medium/High Integrity
includes hardcoded exploit examples (not perfect and pretty cookie cutter)

Additional Powershell Scripts:
testpoc.ps1 will create dummy services, as Proof of Concept
cleanup will clean up dummy services
