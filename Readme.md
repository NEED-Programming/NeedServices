# Need Services
Identify Modifiable Services to include
- Weak Service Permissions
- Service Binary Permissions
- Potential DLL hijacks
- Registry keys
- Unquoted service paths

- ✨Magic ✨

## Features

- Can be run in Medium\High Integrity
- Pre-canned Exploit Examples
- Export Results to CSV
- Two additional powershell scripts to create vulnerable services as proofs of concept and to clean them up*

## Installation & Execution

Install NeedServices from Github

```sh
cd %DIRECTORY_of_your_choosing%
git clone https://github.com/NEED-Programming/NeedServices.git
or
Code -> Download Zip & unzip into %DIRECTORY% of your choosing
```

```sh
powershell.exe
cd %DIRECTORY_of_your_choosing%\NeedServices
powershell.exe -ep bypass
.\NeedServices.ps1
```
